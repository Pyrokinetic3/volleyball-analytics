# volleyball-analytics
Beginner project for analyzing various volleyball statistics
This tool takes in data from volleyball practice sessions/games and helps answer questions such as:

How did serve success vary across sessions?
Which drill had the most errors?
How much evidence supports these comparisons?

The first release takes a csv file as an input and provides a summary with three charts and a short interpretation.
The later release adds a Streamlit interface with upload, filters, and export.
